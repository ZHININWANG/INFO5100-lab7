# Lab 7 - Student Manager (Java Swing + JDBC + MySQL)

A CRUD app with two views: a Create form and a View panel with a JTable
(select a row, then Edit / Update / Delete).

## How to run
1. Start the MySQL Docker container `some-mysql` (port 3306, root / my-secret-pw).
2. Create the `customerdb` database and `student` table (see DatabaseQueries.sql).
3. Open the `lab7` project in NetBeans, add `lib/mysql-connector-j-26.10.0.jar` to the Classpath.
4. Run `view.MainFrame`.

Screenshots are in the `screenshots` folder.
